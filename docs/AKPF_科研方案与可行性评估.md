# AKPF 科研方案与可行性评估

## 1. 方案定位

AKPF 是一种面向复杂室内无人机避障导航的气动与动力学感知代理风险场方法，全称为 Aerodynamic- and Kinodynamic-aware Surrogate Risk Field。

本方案的目标不是构建高保真 CFD 流场，也不是把传统人工势场直接迁移到无人机上，而是为强化学习避障策略提供一种结构化、低维、可实时查询的物理先验表示。它将无人机的制动边界、控制时延、速度方向前视风险、近壁/近地扰动风险和平滑对称破缺机制统一到局部风险场中，用于观测编码、奖励塑形和安全约束。

一句话概括：

```text
用可计算的代理风险场，把室内无人机避障从纯几何感知问题，转化为气动与动力学边界感知的局部决策问题。
```

## 2. 研究背景

室内无人机避障不仅是几何避障问题，还受到飞行器动力学和近场扰动的共同影响。

主要困难包括：

- 空间狭窄，障碍密集，安全余量小；
- 无人机有速度、制动距离、控制时延和欠驱动约束；
- 近墙、近地、近桌面和近天花板飞行会带来状态相关扰动；
- 对称窄门、正前障碍和走廊入口容易导致悬停、左右摆动和高频控制抖动；
- 直接依赖深度图、点云或体素图的强化学习策略需要自行学习隐式物理推理，样本效率和 sim-to-real 鲁棒性存在风险。

因此，本项目把研究重点放在“强化学习策略应该看到什么样的环境表示”上，而不是单纯扩大网络规模或增加训练随机性。

## 3. 研究目标

本项目拟完成以下目标：

1. 提出适用于复杂室内无人机避障的 AKPF 代理风险场表示。
2. 将制动距离、控制时延和速度方向风险编码为动力学有效距离。
3. 构建近壁、近地和近桌面飞行的气动风险代理项。
4. 设计面向连续控制的平滑旋度对称破缺机制，降低悬停和 chattering。
5. 将 AKPF 接入强化学习策略的观测、奖励函数和 Safety Shield。
6. 建立仿真和实机验证流程，比较 AKPF 与原始深度图、体素栅格、距离图和传统 APF 方法的差异。

## 4. 核心科学问题

### 4.1 如何编码无人机的动力学安全边界

在高速或受限空间飞行中，安全距离不只取决于机体半径和障碍物距离，还取决于当前速度、最大可制动加速度和系统总时延。

本项目关注的问题是：如何用低计算代价的场表示描述“当前状态下是否还能安全停下或绕开”。

### 4.2 如何表达几何观测不可见的近场气动风险

近墙、近地、近桌面飞行时，几何上可通行的空间不一定是控制上安全的空间。策略如果只看到距离信息，可能会学习到贴壁或贴桌面飞行的危险行为。

本项目不追求精确流体仿真，而是构建与距离、表面法向和机体状态相关的 surrogate risk，用于训练和决策。

### 4.3 如何缓解对称场景中的局部冲突

正前障碍、对称窄门和狭长走廊入口会使左右方向风险接近，从而引发悬停、方向硬切换和高频抖动。

本项目尝试用连续的旋度偏置场提供切向绕行趋势，避免离散候选方向硬切换。

### 4.4 如何满足机载实时性

AKPF 涉及局部地图、ESDF、风险查询、策略推理和 Safety Shield。工程上必须采用分层频率解耦，避免把所有模块都压到控制频率下运行。

## 5. AKPF 方法建模

AKPF 由四个部分组成：

1. 目标吸引势能；
2. 动力学膨胀排斥势能；
3. 气动风险代理惩罚势能；
4. 平滑对称破缺旋度偏置场。

### 5.1 局部地图与变量

设无人机位置为 `p_t`，速度为 `v_t`，目标位置为 `g`。维护以无人机为中心的局部地图窗口 `Omega_t`。

关键变量包括：

```text
d_t(x)       点 x 到最近障碍物的有符号距离
n_t(x)       最近障碍物表面外法向量
v_hat_t      当前速度单位方向
t_delay      系统总时延
a_max        最大可实现制动加速度
Z_b_t        机体系 Z 轴单位向量
```

一个典型局部窗口可以取：

```text
10 m x 10 m x 5 m, resolution = 0.10 m
```

体素数量约为：

```text
100 x 100 x 50 = 500,000
```

因此工程实现中建议采用：

```text
局部地图 / ESDF 更新：5-10 Hz
AKPF 查询与编码：20-50 Hz
控制输出：50 Hz 及以上
```

### 5.2 目标吸引势能

目标吸引项可定义为：

```text
U_att,t(x) = eta_a * rho_t(x, g)
```

其中 `rho_t(x, g)` 是从点 `x` 到目标 `g` 的局部可达代价。早期实现可先使用欧氏距离，后续再替换为局部 geodesic 代价。

### 5.3 动力学有效距离

传统势场通常直接使用几何距离 `d_t(x)`。AKPF 引入动力学有效距离：

```text
v_n,t(x) = max(0, -v_t^T n_t(x))
d_brake,t(x) = v_n,t(x)^2 / (2 * a_max)
d_delay,t = ||v_t|| * t_delay
d_eff,t(x) = d_t(x) - d_brake,t(x) - d_delay,t
```

直观含义：

- 障碍物越近，风险越高；
- 朝向障碍物的速度越大，制动距离越长；
- 系统时延越大，实际安全边界越保守；
- 当前状态下已经来不及刹停时，`d_eff <= 0`。

动力学排斥势能可写为：

```text
U_kino,t(x) = 0.5 * eta_r * (1 / d_eff,t(x) - 1 / d0)^2, if 0 < d_eff,t(x) <= d0
U_kino,t(x) = 0,                                           if d_eff,t(x) > d0
U_kino,t(x) = U_max,                                       if d_eff,t(x) <= 0
```

这是本方案中最稳健、最容易验证的模块。

### 5.4 气动风险代理势能

气动风险项不尝试求解真实流场，而是构造一个与近场飞行风险一致的代理风险。

水平面敏感度：

```text
w_h,t(x) = max(0, e_z^w · n_t(x))
```

近壁敏感度：

```text
w_w,t(x) = ||(I - e_z^w e_z^{wT}) n_t(x)||
```

气动风险代理势能：

```text
U_aero,t(x) =
  eta_aero * [
    gamma_h * w_h,t(x) * exp(-d_t(x) / H_h)
    + gamma_w * w_w,t(x) * exp(-d_t(x) / H_w)
  ]
```

如果考虑姿态和下洗方向，可加入：

```text
U_aero+,t(x) = U_aero,t(x) * (1 + gamma_z * max(0, -Z_b_t · n_t(x)))
```

论文表述中应明确：该项是 surrogate risk field，不是 CFD 模型。它的验证目标是提升鲁棒性，而不是证明流场精确。

### 5.5 总势能与引导场

总势能：

```text
U_t(x) = U_att,t(x) + U_kino,t(x) + U_aero+,t(x)
```

引导场：

```text
F_t(x) = -grad U_t(x)
```

工程中可以通过 ESDF 梯度和数值差分近似计算，不要求解析闭式解。

## 6. 平滑旋度对称破缺

在正前障碍和对称窄门场景中，单纯依赖梯度场可能产生局部极小或左右方向等价问题。

定义正前方最近障碍物法向为 `n_front,t`，旋度偏置场为：

```text
F_curl,t = beta_sym * (e_z^w x n_front,t)
```

平滑激活权重：

```text
alpha_sym,t =
  sigmoid(k_s * (epsilon_sym - ||F_bar_t||))
  * sigmoid(k_d * (d_sym - d_front,t))
```

最终引导场：

```text
F_final,t = F_bar_t + alpha_sym,t * F_curl,t
```

需要注意：`F_curl` 的方向选择不能过强依赖单一法向。后续工程实现建议加入目标方向、历史绕行方向或自由空间评分，避免固定偏向一侧或诱导贴障。

## 7. 强化学习框架

### 7.1 控制架构

建议采用分层控制架构：

```text
飞控内环：姿态稳定与角速度控制
RL 策略：输出局部速度指令或局部轨迹参考
Safety Shield：在高风险条件下裁剪动作或触发减速
```

策略动作：

```text
a_t = [vx_cmd, vy_cmd, vz_cmd, yaw_rate_cmd]
```

本仓库当前选择 ArduPilot 路线，因此后续部署应对齐 `GUIDED` 模式和 MAVROS 速度控制接口，而不是 PX4 `OFFBOARD`。

### 7.2 AKPF 观测编码

采样点集合 `X_t` 可包括：

- 机体中心；
- 若干前向采样点；
- 少量周向风险感知点。

对每个采样点提取：

```text
f_t(k)      = F_t(x_t(k))
ua_t(k)     = U_aero,t(x_t(k))
deff_t(k)   = d_eff,t(x_t(k))
```

完整策略输入可包含：

```text
s_t = [
  O_AKPF,t,
  F_final,t,
  p_t,
  v_t,
  attitude_t,
  omega_t,
  g - p_t,
  q_map_t
]
```

其中 `q_map_t` 表示地图质量或感知置信度。

### 7.3 奖励函数

总奖励可由以下部分组成：

```text
r_t =
  r_prog,t
  + r_align,t
  + r_safe,t
  + r_aero,t
  + r_smooth,t
  + r_goal,t
  + r_col,t
  + r_timeout,t
```

建议从最小可用奖励开始，不要一开始叠加所有项。

推荐加入顺序：

1. `progress + goal + collision + timeout`
2. `smooth`
3. `U_kino / d_eff` 安全惩罚
4. `F_final` 方向对齐
5. `U_aero` 风险惩罚

这样更容易定位每个模块的贡献。

### 7.4 Safety Shield

当最小动力学有效距离低于阈值时，对速度指令进行裁剪：

```text
vx_cmd <- clip(vx_cmd, -v_back, v_safe(deff_min,t))
```

必要时触发减速、悬停或后退保护。

Safety Shield 应同时用于训练和测试，避免训练-部署不一致。

## 8. 训练期气动扰动注入

为避免高保真 CFD 的计算成本，训练期通过物理引擎向机体施加状态依赖外力和外矩。

近地/近桌面扰动：

```text
f_ground,t = k_g * exp(-h_t / H_g) * s_g,t * e_z^w
tau_ground,t = k_taug * exp(-h_t / H_taug) * xi_att,t
```

近壁扰动：

```text
f_wall,t = k_w * exp(-d_wall,t / H_w) * n_wall,t
tau_wall,t = k_tauw * exp(-d_wall,t / H_tauw) * (Z_b_t x n_wall,t)
```

角隅增强：

```text
A_corner,t = 1 + k_c * sum_{i<j} exp(-(d_i + d_j) / H_c)
```

最终扰动：

```text
f_aero,t = A_corner,t * (f_ground,t + f_wall,t) + w_f,t
tau_aero,t = A_corner,t * (tau_ground,t + tau_wall,t) + w_tau,t
```

其中 `w_f,t` 和 `w_tau,t` 应使用有色噪声和分布随机化，避免训练扰动过于理想。

## 9. 实验设计

### 9.1 研究假设

```text
H1: AKPF 相比深度图、体素栅格和距离图，能提高成功率并降低碰撞率。
H2: 动力学有效距离能在高速或狭窄场景中提升安全裕度和提前减速能力。
H3: 气动风险项与扰动注入共同作用时，可提升近壁/近地场景鲁棒性。
H4: 平滑旋度偏置场能降低对称场景中的悬停率、摆动率和 chattering。
```

### 9.2 对比基线

- APF + PID
- APF + MPC
- Depth + PPO/SAC
- Voxel + PPO/SAC
- Distance Map + PPO/SAC
- AKPF 完整方法

- AKPF 用离散候选方向替代平滑旋度偏置

### 9.3 场景类型

当前仓库已经包含 L2 最小场景集，可作为早期验证入口：

```text

S3_corridor
S4_table_or_low_obstacle

```

后续可扩展：

- 高速正前障碍制动；
- 近墙侧向飞行；
- 贴近桌面/地面飞行；
- 上下受限空间；
- 走廊转角；
- 桌椅密集房间；

### 9.4 评价指标

核心指标：

```text
SR   Success Rate
```

建议额外记录：

- 速度指令裁剪次数；
- Safety Shield 触发时间占比；
- 近壁/近地飞行时间占比；
- 每个模块平均耗时和峰值耗时。

## 10. 与当前仓库工程路线的关系

当前仓库已经完成或正在固化：

```text
L0 ArduPilot 基线链路
L1 ArduPilot 速度控制闭环
L2 室内仿真场景与实验协议
```

建议后续路线：

```text
L3 真值几何 AKPF 非学习版
L4 点云 / 局部地图 AKPF
L5 Safety Shield 安全层
L6 简化环境强化学习
L7 ROS2 / Gazebo 策略部署
L8 近壁 / 近地扰动注入
L9 系统实验、消融与论文固化
```

实施原则：

- 不跳层；
- 每层先做可重复验收；
- 每个新增模块都必须有消融；
- 先仿真闭环，再做实机；
- 先证明动力学风险项，再证明气动代理项。

## 11. 可行性评估

### 11.1 总体结论

本方案技术上可行，适合作为物理先验引导强化学习避障的科研框架。

最稳健的主线是：

```text
动力学有效距离
  -> 结构化风险观测
  -> Safety Shield
  -> 消融实验
  -> 小规模 sim-to-real 验证
```

气动风险代理项和旋度偏置项具有创新性，但需要谨慎表述和严格消融。

### 11.2 高可行性部分

动力学有效距离 `d_eff` 可行性最高，因为它有明确的物理解释和可测指标。

可直接验证：

- 高速接近障碍时是否提前减速；
- 最小安全距离是否增大；
- 碰撞率是否下降；
- Safety Shield 触发是否更少；
- 相同场景下是否比原始深度/距离图更快收敛。

结构化观测编码也较可行。它降低了策略从高维几何输入中学习动力学边界的难度，理论上有助于样本效率。

### 11.3 中等风险部分

气动风险代理项是中等风险模块。

风险在于：

- 它不是高保真气动模型；
- 容易被质疑只是距离惩罚的另一种写法；
- 如果没有实飞或扰动验证，贡献不够独立。

应对方式：

- 明确称为 surrogate risk，不声称精确还原流场；
- 通过近壁、近地、角隅扰动测试证明鲁棒性；
- 使用 `w/o U_aero` 和 `w/o aero disturbance` 两个消融分离观测先验和训练扰动的作用；
- 用少量实飞日志标定扰动数量级。

### 11.4 需要控制的部分

旋度偏置场有潜力，但需要防止副作用。

主要风险：

- 旋度方向可能固定偏向一侧；
- 在角隅或复杂障碍中可能诱导贴障；
- 激活过强会带来非最优绕行；
- 与目标吸引项冲突时可能产生额外震荡。

建议：

- 只在局部极小和前方受阻时激活；
- 使用平滑权重而非硬切换；
- 加入目标方向或历史绕行方向；
- 将 `beta_sym` 作为重点消融参数；
- 评价悬停率、摆动率、chattering 和平均通过时间。

### 11.5 最大工程风险

最大工程风险不是数学公式，而是实验链路复杂度。

需要同时稳定：

- ArduPilot SITL；
- Gazebo 场景；
- MAVROS 速度控制；
- 局部地图 / ESDF；
- 风险场查询；
- 策略训练；
- Safety Shield；
- 日志记录和评价脚本。

因此应优先把数据记录和评价协议做扎实。没有统一日志，后续很难证明每个模块有效。

## 13. 论文表述建议

建议避免过强表述：

```text
首次提出真实气动风险场
精确建模近壁流体扰动
完整解决室内无人机 sim-to-real
```

建议使用更稳健的表述：

```text
提出一种面向室内无人机强化学习避障的气动与动力学感知代理风险场。
该风险场将制动边界、控制时延、近场扰动先验和平滑对称破缺统一为可查询的局部表示。
实验验证该结构化表示在样本效率、安全裕度、控制平滑性和扰动鲁棒性上优于原始几何感知表示。
```

## 14. 结论

AKPF 方案具备较好的科研可行性和工程落地潜力。

它的核心优势在于把无人机避障中的关键物理先验显式前置到环境表示层，而不是完全交给强化学习策略从原始感知中隐式学习。动力学有效距离是最可靠的基础贡献，气动风险代理和旋度偏置则提供进一步创新空间。

后续工作应围绕一个原则展开：

```text
每一个物理先验都必须对应一个可测指标、一个消融实验和一个失败边界。
```

只要实验设计保持清晰，AKPF 可以形成一条从仿真平台、风险场方法、强化学习策略到小规模实机验证的完整科研路线。
